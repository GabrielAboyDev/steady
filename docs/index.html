How it works

After each letter, only a few words are still possible.

Steady works out which ones, and hands the keyboard over to the letters that can still get you there.

1

It reads the word you are in

Only the letters between the last space and your cursor. They are used in memory, on your device, and discarded as soon as the next key is drawn.

2

It finds every word that still fits

A 47,000-word dictionary ships inside the app as a compiled trie. Type toget and exactly one letter in the alphabet can follow it — so that key gets the row to itself.

3

It resizes the keys

Likely letters grow in place. Impossible ones shrink away or leave the row entirely, so there is nothing there to mis-hit.

Built around the miss

Designed so the keyboard never works against you.

Keys never move

Rows keep a fixed height and keys keep their order. A key only ever grows or shrinks where it already is — it never slides out from under the finger already on its way to it.

Nothing is corrected behind your back

Steady offers completions on three large chips. It never silently rewrites a word you typed, so what lands in the field is what you chose.

You set how strong it is

Off keeps every key the same size. Medium grows likely letters gently. Aggressive uses the full size range. Separate switches control whether impossible letters are removed or just shrink, and whether likely letters grow at all.

Names and phrases

Names insert exactly as written, for the proper nouns prediction will never guess. Phrases are sentences with fill-in-the-blank slots that walk you through each blank with large chips.

Privacy

A keyboard that physically cannot send your typing anywhere.

Most keyboards ask for “Allow Full Access”. That permission is what lets a keyboard reach the network at all. Steady never asks for it.

  • No network code, no servers, no analytics, no crash reporters, no ads.
  • The dictionary is a static file inside the app. Every lookup is local.
  • Your names, phrases and settings stay in Steady’s own container on your device.
  • Nothing is collected, so there is nothing to leak, sell, or subpoena.

Questions

Common questions about Steady

Who is Steady for?

Anyone who misses keys on a touchscreen. It is built around tremor, limited dexterity, and single-finger or switch typing — the situations a fixed grid of small keys fights hardest. Steady is a typing aid, not a medical device, and makes no clinical claims.

Does Steady work in every app?

Steady is a system keyboard, so it works anywhere you can type: Messages, Mail, Notes, Safari, WhatsApp. Password and other secure fields are the exception — there Steady deliberately falls back to a plain fixed layout, because reshaping the keys would reveal something about what you are typing.

Does Steady replace the built-in iPhone keyboard?

No. It installs alongside it. Press and hold the globe key to switch between them, so the standard keyboard is always one press away.

Which devices does Steady run on, and what does it cost?

iPhone and iPad running iOS 16 or later. Steady is free — no account, no subscription, no ads — and the open beta is distributed through TestFlight, which anyone can join without an invite code.

Does Steady autocorrect what I type?

No. Steady offers completions on three large chips and inserts one only if you tap it. It never silently rewrites a word you have already typed, so what lands in the field is what you chose.

Does Steady collect any data?

No. Steady never asks for “Allow Full Access”, which is the permission a keyboard needs to reach the network at all. The dictionary is a static file inside the app and every lookup is local, so your typing cannot leave the device. There are no servers, analytics, crash reporters or ads.

What languages does Steady support?

English only for now. The prediction engine reads a compiled dictionary file rather than anything language-specific, so further languages are a matter of building them, not rewriting the keyboard.

Where do I get help?

The support page covers installing the beta, enabling the keyboard in Settings, the resize strengths, names and phrases, and what to do when something looks wrong.
